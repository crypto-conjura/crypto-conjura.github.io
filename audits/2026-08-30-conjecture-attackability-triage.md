## 9. First three campaigns

**1. c/0076** (GO, 1 routine, total 26)
- entry rung: A perfect M-FASS scheme for $3$-out-of-$5$ with $|S| = 2$
- plan class: exhaustive finite search, with Con's Reed-Solomon route as the structured alternative
- milestone: Settle 3-out-of-5 by exhaustive search over share domains up to a fixed size, which decides the smallest open case outright.
- yield on failure: A non-existence certificate at the smallest case, which would settle the source's question negatively for all larger thresholds it names.
- human input needed first: the share-domain size bound at which exhaustive search is declared conclusive

**2. c/0084** (GO, 2 reachable, total 23)
- entry rung: $|S(H,\chi)| \le \eta(n)|\chi(n)|$ for a $1-o(1)$ fraction of $H$, at small $n$
- plan class: exhaustive computation first, then a concentration argument
- milestone: Enumerate all graphs to n = 8 and decide whether the o(1) shape is plausible at all.
- yield on failure: A numerical picture of the character sum, which does not currently exist.
- human input needed first: what rate of decay eta is wanted, which the source does not state

**3. c/0096** (GO, 1 routine, total 27)
- entry rung: A conflict checkable, local-to-global consistent code with $k > (n-d+2)/2$ at some $1 < d < n-1$
- plan class: test the source's almost-MDS construction for local-to-global consistency, then exhaustive search at small n
- milestone: Check whether the Theorem 1.3 code is local-to-global consistent, which may settle the conjecture immediately.
- yield on failure: A demonstration that comparison-basedness is not the culprit, which would redirect the question.
- human input needed first: whether the alphabet size may grow with n
