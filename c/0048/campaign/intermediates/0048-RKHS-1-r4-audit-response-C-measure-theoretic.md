Verified line by line. `dμ′ := k dμ` is a probability measure by Lemma 2(ii) plus `k ≥ 0` a.e.; `E_{μ′}[vv^T] = v_0v_0^T` by Lemma 2(i); for unit `w ⊥ v_0`, `E_{μ′}⟨v,w⟩² = w^Tv_0v_0^Tw = 0` so `⟨v,w⟩ = 0` `μ′`-a.s.; intersecting the `n−1` full-measure sets from an orthonormal basis of `v_0^⊥` and using `‖v‖₂ = 1` gives `v = ±v_0` `μ′`-a.s.
