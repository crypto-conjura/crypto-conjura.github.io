## GOAL (self-contained)

Let `n ≥ 1`, `S^{n-1} = {v ∈ R^n : ‖v‖₂ = 1}`, and let `μ` be a Borel probability
measure on `S^{n-1}`. Call a Borel measurable, `μ`-integrable `r : S^{n-1} → R`
(not required nonnegative) a *signed reweighting of `μ` with entropy cost at most
`K`* if `E_{v∼μ}|r(v)| = 1` and `E_{v∼μ}[|r(v)| log|r(v)|] ≤ K` (convention
`0 log 0 := 0`).

Claim: for every `ε > 0` and every `δ > 0` there is a finite `C = C(ε,δ)`,
independent of `n` and `μ`, such that for every `n` and every such `μ` there
exist a signed reweighting `r` of `μ` of entropy cost at most `C·n^δ` and a
**nonzero rank one** `L ∈ R^{n×n}` with
`‖E_{v∼μ}[r(v) v v^T] − L‖_F ≤ ε‖L‖_F`.

Proved below with `C(ε,δ) = 2/(eδ)` — no dependence on `ε` — and with the
Frobenius error equal to `0`.

## THEOREM

For every `n ≥ 1` and every Borel probability measure `μ` on `S^{n-1}` there
exist a point `v_0 ∈ supp μ`, a constant `c` with
`(n(n+1)/2)^{-1/2} ≤ c ≤ 1`, and a signed reweighting `r` of `μ` — indeed the
restriction to `S^{n-1}` of a single quadratic form, hence a bounded Borel
function — such that

    E_{v∼μ}[ r(v) v v^T ] = c · v_0 v_0^T      (exactly)

and

    E_μ[ |r| log|r| ]  ≤  log K(v_0,v_0)  ≤  log( n(n+1)/2 ).

Here `L := c v_0v_0^T` is rank one, nonzero and PSD, with `‖L‖_F = c`.

### Proof plan

`F_μ ⊆ L²(μ)` := the classes of the quadratic forms `q_Q(v) = v^T Q v`;
`d := dim F_μ ≤ n(n+1)/2`. On the sphere the constant function `1` *is* the
quadratic form `q_I`, and each coordinate product `v_a v_b` is the quadratic form
`q_{E_{ab}}`. Hence the reproducing kernel `k = k_{v_0}` of `F_μ` at a support
point `v_0` satisfies simultaneously `E_μ[k] = 1` (free normalisation) and
`E_μ[k(v)vv^T] = v_0v_0^T` (exact rank one). Its *squared* `L²` norm averages to
`d` over `μ`, so some base point is cheap; and entropy is bounded by the log of
the second moment. Cancellation is available through `k`, which is negative
somewhere whenever `E_μ|k| > E_μ[k] = 1`.

### Lemma 1 (the quadratic space, evaluation on the support, and its kernel)

Let `F_μ := { [q_Q] ∈ L²(μ) : Q ∈ Sym_n }`, `d := dim F_μ`. Then
(a) `F_μ` is a subspace of `L^∞(μ) ∩ L²(μ)` with `d ≤ n(n+1)/2` and
    `‖q_Q‖_∞ ≤ ‖Q‖_F`;
(b) if `q_Q = q_{Q'}` `μ`-a.e. then `q_Q(v) = q_{Q'}(v)` for **every**
    `v ∈ supp μ`; hence `ev_v : F_μ → R`, `[q_Q] ↦ q_Q(v)`, is well defined and
    linear for `v ∈ supp μ`;
(c) for each `v ∈ supp μ` there is a unique `k_v ∈ F_μ` with
    `⟨k_v,f⟩_{L²(μ)} = ev_v(f)` for all `f ∈ F_μ`; set
    `K(v,v) := ‖k_v‖²_{L²(μ)} = ev_v(k_v)`;
(d) `[1] = [q_I] ∈ F_μ`, and `[v ↦ v_a v_b] = [q_{E_{ab}}] ∈ F_μ` where
    `E_{ab} = (e_ae_b^T + e_be_a^T)/2`.

*Preliminaries.* (P1) `μ(supp μ) = 1`: the complement of the support is a union
of open null sets, and `S^{n-1}` is second countable, so that union is a
countable union of null sets. (P2) `v ∈ supp μ` and `U ∋ v` open imply
`μ(U) > 0` (definition of support).

*Proof.* (a) `Q ↦ q_Q` is linear, so `F_μ` is the image of `Sym_n` and
`d ≤ n(n+1)/2`. For `v ∈ S^{n-1}`, `|v^TQv| ≤ ‖Q‖_op‖v‖₂² = ‖Q‖_op ≤ ‖Q‖_F`.
Since `μ` is a probability measure, `L^∞(μ) ⊆ L²(μ)`.

(b) Put `h := q_{Q−Q'}`, continuous, with `μ({h ≠ 0}) = 0`. If `h(v_0) ≠ 0` for
some `v_0 ∈ supp μ`, then `U := {|h| > |h(v_0)|/2}` is open, contains `v_0`, so
`μ(U) > 0` by (P2); but `U ⊆ {h ≠ 0}` is null. Contradiction. Well-definedness of
`ev_v` follows: `ev_v` is defined through quadratic-form representatives only,
and by the displayed statement of (b) any two quadratic-form representatives of
the same class of `F_μ` take the same value at every `v ∈ supp μ`; linearity is
inherited from `Q ↦ q_Q(v)`.

(c) `F_μ` is a finite-dimensional subspace of `L²(μ)`, hence a Hilbert space;
`ev_v` is a linear functional on it, hence bounded, hence has a unique Riesz
representer `k_v ∈ F_μ`. Explicitly `k_v = Σ_j ev_v(f_j) f_j` for any orthonormal
basis `(f_j)`. Taking `f = k_v` gives `K(v,v) = ev_v(k_v)`.

(d) `q_I(v) = ‖v‖₂² = 1` identically on `S^{n-1}`; `q_{E_{ab}}(v) = v_av_b`
identically. ∎

*(Note: (b) is the only place where the general Borel case differs from the
finitely supported case, and it removes the need for any approximation argument;
for finitely supported `μ` it is trivial, every support point being an atom.)*

### Lemma 2 (three reproducing identities)

Let `v_0 ∈ supp μ`, `k := k_{v_0}`. Then
(i) `E_μ[k(v) v v^T] = v_0 v_0^T`;
(ii) `E_μ[k] = 1`; hence `E_μ|k| ≥ 1`, `K(v_0,v_0) ≥ 1`, and `k ≠ 0`;
(iii) `E_μ[k²] = K(v_0,v_0)` and `1 ≤ E_μ|k| ≤ K(v_0,v_0)^{1/2} < ∞`.

*Proof.* All integrals converge absolutely: `k` is bounded (Lemma 1(a)) and the
other factors are bounded by `1` on `S^{n-1}`.

(i) Fix `a,b`. By Lemma 1(d), `g_{ab} := [v ↦ v_av_b] ∈ F_μ`, so the reproducing
property gives `E_μ[k v_a v_b] = ⟨k, g_{ab}⟩ = ev_{v_0}(g_{ab}) = (v_0)_a(v_0)_b`.
The `(a,b)` entries of the two matrices therefore agree, for all `a,b`.

(ii) By Lemma 1(d), `[1] ∈ F_μ` with `ev_{v_0}([1]) = q_I(v_0) = 1`, so
`E_μ[k] = ⟨k,[1]⟩ = 1`. Then `E_μ|k| ≥ |E_μ k| = 1` and, by Cauchy–Schwarz,
`K(v_0,v_0) = E_μ[k²] ≥ (E_μ|k|)² ≥ 1`. And `E_μ[k] = 1 ≠ 0` forces `k ≠ 0`.

(iii) `K(v_0,v_0) = ‖k‖² = E_μ[k²]` by definition; finiteness is Lemma 1(a); the
upper bound on `E_μ|k|` is Cauchy–Schwarz against `1`. ∎

*Structural note: (ii) is exactly the trace of (i), since
`tr E_μ[k vv^T] = E_μ[k‖v‖₂²] = E_μ[k]` and `tr(v_0v_0^T) = 1`. This locates
where the construction gets its normalisation for free: the sphere constraint
`‖v‖₂ = 1` is what makes the constant function a quadratic form.*

### Lemma 3 (a cheap base point exists)

`∫ K(v,v) dμ(v) = d`, and consequently there exists `v_0 ∈ supp μ` with
`K(v_0,v_0) ≤ d ≤ n(n+1)/2`.

*Proof.* Fix an orthonormal basis `f_1,…,f_d` of `F_μ` and quadratic-form
representatives `q_j` of `f_j`. For `v ∈ supp μ`, Lemma 1(c) and Parseval give
`k_v = Σ_j q_j(v) f_j` and hence

    K(v,v) = Σ_{j=1}^d q_j(v)²  =: g(v)     for all v ∈ supp μ.   (2)

`g` is a polynomial, hence Borel, and by (P1) it represents `v ↦ K(v,v)` up to a
null set, so the integral is well defined and

    ∫ K(v,v) dμ = Σ_j ∫ q_j² dμ = Σ_j ‖f_j‖² = d.   (3)

(For `v ∈ supp μ` the value `g(v) = ‖k_v‖²` is independent of the choices, by
uniqueness in Lemma 1(c); off the support nothing below uses `g`.)

Let `A := {g ≤ d}`, Borel. If `μ(A) = 0` then `h := g − d` satisfies `h > 0`
`μ`-a.e. while `∫ h dμ = 0` by (3); a nonnegative function with vanishing
integral vanishes a.e., so `h = 0` `μ`-a.e., which cannot hold simultaneously
with `h > 0` `μ`-a.e. under a probability measure. So `μ(A) > 0`, hence by (P1)
`A ∩ supp μ ≠ ∅`; any `v_0` in it satisfies `K(v_0,v_0) = g(v_0) ≤ d`. ∎

*(3) is the identity `∫K(v,v)dμ = tr P` for `P` the orthogonal projection onto
`F_μ`, i.e. the mean of the reciprocal Christoffel function; it is proved here
from scratch.*

### Lemma 4 (entropy at most the log of the second moment)

If `r ∈ L²(μ)` and `E_μ|r| = 1`, then `E_μ[|r| log|r|] ≤ log E_μ[r²]`.

*Proof.* Write `φ(t) = t log t`, `φ(0) = 0`. Then `φ(t) ≥ −1/e` for `t ≥ 0`, and
`φ(t) ≤ t²` for all `t ≥ 0` (for `t ≥ 1` because `log t ≤ t`; for `t < 1` because
`φ ≤ 0`). Since `r ∈ L²(μ)` and `μ` is a probability measure, `φ(|r|) ∈ L¹(μ)`,
so the entropy is a finite real number.

Let `dν := |r| dμ`; then `ν(S^{n-1}) = 1`, so `ν` is a probability measure, and
`ν({r = 0}) = 0`, so `log|r|` is `ν`-a.e. finite and
`E_ν[log|r|] = E_μ[|r| log|r|]` (the convention `0 log 0 = 0` matching the
`ν`-null set `{r = 0}`). Also `E_ν[|r|] = E_μ[r²] < ∞`. Jensen's inequality for
the concave function `log` against `ν` gives
`E_ν[log|r|] ≤ log E_ν[|r|] = log E_μ[r²]`. ∎

*Sharpness: equality holds iff `|r| ∈ {0,c}` `μ`-a.e., i.e. exactly on the
indicator-type ("conditioning on an event") reweightings, where the bound reads
`log(1/μ({|r| = c}))`. The bound is lossy precisely to the extent that `|r|` is
spread out.*

### Proof of the Theorem

Let `n` and `μ` be given. Lemma 3 supplies `v_0 ∈ supp μ` with
`K(v_0,v_0) ≤ d ≤ n(n+1)/2`; let `k := k_{v_0}`. By Lemma 2(ii,iii),
`1 ≤ E_μ|k| ≤ K(v_0,v_0)^{1/2} < ∞` and `k ≠ 0`, so

    c := 1 / E_μ|k|  ∈  [ K(v_0,v_0)^{-1/2}, 1 ]  ⊆  [ (n(n+1)/2)^{-1/2}, 1 ].

Set `r := c·k`, taking as representative the quadratic form `q_{cQ_k}`; then `r`
is a bounded Borel function on `S^{n-1}`, hence `μ`-integrable, and
`E_μ|r| = c E_μ|k| = 1`. So `r` is admissible for Definition `def:signed`.

*Second moment.* By Lemma 2(i), `E_μ[r(v)vv^T] = c·v_0v_0^T =: L`. As `c > 0` and
`‖v_0‖₂ = 1`, `L = (c v_0)v_0^T` is rank one, nonzero, PSD, with `‖L‖_F = c > 0`.
The Frobenius error is `0 ≤ ε‖L‖_F` for every `ε > 0`.

*Entropy.* `r ∈ L²(μ)` with `E_μ|r| = 1`, so Lemma 4 and Lemma 2(iii) give

    E_μ[|r| log|r|] ≤ log E_μ[r²] = log( c² K(v_0,v_0) )
                    = log( K(v_0,v_0) / (E_μ|k|)² )
                    ≤ log K(v_0,v_0)  ≤  log( n(n+1)/2 ),

using `E_μ|k| ≥ 1` and Lemma 3. ∎

### COROLLARY (the Contract / Question 8.1)

Conjecture `conj:main` holds with `C(ε,δ) := 2/(eδ)`, independent of `ε`.

*Proof.* For `n = 1`, `log(n(n+1)/2) = log 1 = 0`. For `n ≥ 2`,
`n(n+1)/2 ≤ n²`, so `log(n(n+1)/2) ≤ 2 log n`; and
`max_{x>0} (log x)/x^δ = 1/(eδ)` (attained at `x = e^{1/δ}`), so
`2 log n ≤ (2/(eδ)) n^δ`. Combine with the Theorem. ∎

### REMARK A (the conclusion is not obtainable by cancelling to zero)

Let `M ∈ Sym_n` with eigenvalues indexed so that `|λ_1| ≥ |λ_2| ≥ …`, and let
`ε ∈ (0,1)`.
* If `M = 0`, no admissible `L` exists: `‖0 − L‖_F = ‖L‖_F > ε‖L‖_F` for every
  `L ≠ 0`.
* If `M ≠ 0`, a nonzero rank one `L` with `‖M − L‖_F ≤ ε‖L‖_F` exists **iff**
  `Σ_{i≥2} λ_i² ≤ (ε²/(1−ε²)) λ_1²`.

*Proof.* Write `L = t u w^T`, `‖u‖ = ‖w‖ = 1`, `t > 0`, so `‖L‖_F = t` and
`‖M − L‖_F² = ‖M‖_F² − 2t·u^TMw + t²`. The requirement is
`(1−ε²)t² − 2(u^TMw)t + ‖M‖_F² ≤ 0`, and increasing `u^TMw` only helps, so the
optimal choice is `u^TMw = s_1(M) = |λ_1|` (SVD). The quadratic in `t` has a real
root iff `s_1² ≥ (1−ε²)‖M‖_F² = (1−ε²)Σ_i λ_i²`, which rearranges to the stated
inequality; when `M ≠ 0` both roots are positive (their product is
`‖M‖_F²/(1−ε²) > 0`, their sum `2s_1/(1−ε²) > 0`), so an admissible `t > 0`
exists exactly then. ∎

(Not load-bearing; recorded because it shows the relative normalisation in the
Contract does real work, so the Theorem is not exploiting a degenerate reading.)

### COROLLARY B (the same for distributions over rank one matrices of unit Frobenius norm)

Let `X := {X ∈ R^{n×n} : rank X = 1, ‖X‖_F = 1}` — equivalently `X = ab^T` with
`‖a‖₂ = ‖b‖₂ = 1`, the normalisation used in the source paper's intended
application (§2.3: "we will restrict our attention to the case that all the
columns of `U` and `V` are of unit norm. (This restriction is easy to lift and
anyway holds automatically in our intended application.)"). Let `μ` be a Borel probability measure
on `X`. Then there exist `X_0 ∈ supp μ`, `c ∈ (0,1]`, and a signed reweighting
`r` of `μ` with `E_μ[|r| log|r|] ≤ log(n²+1)` such that
`E_{X∼μ}[r(X)·X] = c·X_0`, exactly rank one and nonzero.

*Proof.* Run Lemmas 1–4 verbatim with `S^{n-1}` replaced by `X` (compact) and the
space of quadratic forms replaced by the affine space
`G := {X ↦ α + ⟨A,X⟩ : α ∈ R, A ∈ R^{n×n}}`, of dimension at most `n²+1`. Only
two properties of the function space were used: it contains the constant `1`
(here trivially, `α = 1, A = 0`) and it contains each coordinate function
`X ↦ X_{ab}` (here `α = 0, A = e_ae_b^T`). Continuity of the elements of `G`
gives Lemma 1(b) unchanged; boundedness on `X` gives Lemma 1(a). ∎

*(So the mechanism is not an artefact of specialising to `X = vv^T`: it is the
presence of constants and coordinates in one finite-dimensional function space.
On the sphere the homogeneous quadratic forms suffice because `‖v‖₂ = 1` makes
the constant a quadratic form; that only buys the sharper bound
`log(n(n+1)/2)` over `log(n²+1)`.)*

### REMARK C (scope)

The Theorem answers Question 8.1 as literally posed (card Q1) and nothing
more. (i) *No conflict with the source's negative results.* "It can be shown
that as stated, Theorem 2.3 is tight" (Q5) is about *deficient* reweightings,
which are probability distributions and hence nonnegative by Definition 2.2
(Q9); and "the answer to this question is No if one does not allow negative
reweighting functions" (Q1) is an existential statement over `μ`. Neither is
contradicted here, because whenever the construction returns a nonnegative
`r`, that `r` is itself a nonnegative reweighting of entropy cost at most
`log(n(n+1)/2) = O(log n)` — indeed, more precisely, `k ≥ 0` forces
`μ({±v_0}) = 1/K(v_0,v_0) ≥ 2/(n(n+1))` — so such a `μ` is not a hard instance
for the nonnegative question. The same holds for Corollary B, whose domain —
not the sphere — is the one Theorem 2.3 and the tightness claim of Q5 are
stated over; the argument just given does not transfer verbatim, since the
elements of `G` are affine rather than even and the map `X ↦ X` has no
antipodal fibre, so it is redone here. Let `X_0 ∈ supp μ` and `k = k_{X_0}` be
as in the proof of Corollary B, and suppose `k ≥ 0` `μ`-a.e. Then
`E_μ|k| = E_μ[k] = 1`, so `c = 1` and `r = k` is itself a nonnegative
reweighting, of cost at most `log K(X_0,X_0) ≤ log(n²+1)`. Moreover
`dμ′ := k dμ` is a probability measure with `E_{μ′}[X] = X_0`, so
`E_{μ′}⟨X_0,X⟩ = ⟨X_0,X_0⟩ = ‖X_0‖_F² = 1`, while `⟨X_0,X⟩ ≤ ‖X_0‖_F‖X‖_F = 1`
for every `X` in the domain; a nonnegative function with `μ′`-mean zero
vanishes `μ′`-a.s., so `⟨X_0,X⟩ = 1` `μ′`-a.s., and equality in Cauchy–Schwarz
between matrices of unit Frobenius norm forces `X = X_0` `μ′`-a.s. Hence
`μ′({X_0}) = 1`, and evaluating `1 = ∫_{\{X_0\}} k dμ = K(X_0,X_0)·μ({X_0})`
gives `μ({X_0}) = 1/K(X_0,X_0) ≥ 1/(n²+1)` — a single atom, in place of the
antipodal pair of the spherical case. Conditioning on it,
`r′ := 1_{\{X_0\}}/μ({X_0})`, is a nonnegative reweighting with
`E_μ[r′X] = X_0` and cost `log(1/μ({X_0})) = log K(X_0,X_0) ≤ log(n²+1)`, so
the same conclusion holds: a `μ` on which Corollary B returns a nonnegative
reweighting is not a hard instance for the nonnegative question. What is *not*
addressed is the unnormalised domain of Theorem 2.3 (Q2), "any distribution
over rank one `n × n` matrices"; Corollary B treats only the unit-Frobenius
slice named at Q8, and nothing here is claimed beyond that slice. (ii) *No
log-rank consequence is claimed.* The submatrix dictionary quoted at Q4 is
stated for *flat* distributions and the Theorem supplies no flatness
guarantee, so that route is unavailable; no other route is addressed, and
Theorem 2.4 (Q3) is untouched. (iii) *The pseudo-distribution version is out
of scope.* Every use of `supp μ` in the proof — Lemma 1(b),(c), Lemma 2, Lemma
3, the Theorem — presumes an honest distribution. The source attaches its
pseudo-distribution condition to its *running-time* consequence (Q1); this
artifact addresses neither.

*Derivation of the "equivalently" clause of (i), so that this Remark rests on
nothing outside this artifact.* Let `v_0` and `k = k_{v_0}` be as in the proof
of the Theorem, and suppose `k ≥ 0` `μ`-a.e. By Lemma 2(ii), `dμ′ := k dμ` is a
probability measure, and by Lemma 2(i), `E_{μ′}[vv^T] = v_0v_0^T`. For a unit
`w ⊥ v_0` this gives `E_{μ′}⟨v,w⟩² = w^T v_0v_0^T w = 0`, so `⟨v,w⟩ = 0`
`μ′`-a.s.; ranging `w` over an orthonormal basis of `v_0^⊥` and using
`‖v‖₂ = 1` forces `μ′({±v_0}) = 1`. Since `k` is (the class of) a quadratic
form, `k(v_0) = K(v_0,v_0)` by Lemma 1(c), and `k(−v_0) = k(v_0)` because the
chosen representative `q_{Q_k}` is an even function; if `μ({−v_0}) > 0` then
`−v_0` is an atom, hence in `supp μ`, where Lemma 1(b) makes the value
representative-independent, and if `μ({−v_0}) = 0` the term drops for any
representative, so `1 = μ′({±v_0}) = K(v_0,v_0)·μ({±v_0})`, i.e.
`μ({±v_0}) = 1/K(v_0,v_0)`; and `K(v_0,v_0) ≤ n(n+1)/2` by Lemma 3 gives
`μ({±v_0}) ≥ 2/(n(n+1))`. Conditioning on that atom,
`r′ := 1_{{±v_0}}/μ({±v_0})`, is then a nonnegative reweighting reaching
`v_0v_0^T` at entropy cost
`log(1/μ({±v_0})) = log K(v_0,v_0) ≤ log(n(n+1)/2)`, the same bound the Theorem
gives for `r` itself. Every quantity used here is Lemma 1(c), Lemma 2(i),(ii),
Lemma 3 or the Theorem; nothing is taken on the authority of a document outside
this artifact.
